## كيفية العمل / ملخص المشروع
تم تنزيل لقطة كاملة من الموقع الحي (https://abu-nawaf-be6o.arcada.app/) تشمل `index.html` وكل الأصول المحلية (JS/CSS/صور) بتاريخ 2026-10-15، وأصبح المشروع جاهزًا للاستضافة الثابتة مباشرة.

- العنوان الأصلي في الموقع: `ابونواف | هكر أخلاقي | خدمات استعادة الحسابات في السعودية`
- الوصف الأصلي (Meta): هكر أخلاقي سعودي - استعادة الحسابات المخترقة، تأمين الحسابات، مكافحة الابتزاز، فحص الثغرات. خدمات احترافية في الرياض.
- هذا مشروع ويب ثابت: افتح `index.html` مباشرة أو استضِف المجلد كاملًا على GitHub أو Vercel أو Netlify أو أي استضافة ثابتة بدون أي خطوة بناء (No build step).
- كل الأصول المحلية التي كان الموقع يعتمد عليها موجودة داخل المستودع في نفس مساراتها الأصلية (`assets/` وغيرها) حتى يعمل الموقع بعد الاستضافة كما كان حيًا.

## التشغيل محليًا
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الاستضافة على Vercel
```bash
npm i -g vercel
vercel --prod
```
أو اربط هذا المستودع من لوحة Vercel وسيُنشر كموقع ثابت مباشرة.
